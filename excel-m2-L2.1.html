LESSON 2.1

Basic Math Operations & Cell References (A1, $A$1)

Lesson Overview & Key Takeaways

Welcome to Excel! In this lesson, you will learn the core logic behind calculations in Excel:

  • Basic Operators: Writing formulas using +, -, *, and / starting with the = sign.
  • Relative References (A1): Formulas that automatically adjust when copied across rows or columns.
  • Absolute References ($A$1): Using dollar signs or pressing F4 to lock cells in place.
